# RockRockRock — адаптивная версия

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Дисциплина: «Фронтенд и бэкенд разработка».

**Опубликованная версия:** https://ilyaplusrep.github.io/kr3-responsive-shop/

## Описание

Интернет-магазин камней, которые ничего не делают. Основа — HTML/CSS-проект из КР №1 (`kr1-html-css-shop`), Bootstrap не используется. В КР №3 сайт адаптирован под экраны от 360px до 1440px, проведена проверка доступности.

## Адаптивные решения

- Добавлен файл `css/responsive.css`, он подключается после `style.css` на всех 5 страницах.
- На всех страницах есть `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.
- Подход **Mobile First**: `style.css` описывает телефон, а `responsive.css` расширяет вёрстку медиазапросами `min-width`:
  - `480px` — крупный телефон: карточки в 2 колонки, кнопки в строку, таблица в табличном виде;
  - `768px` — планшет: меню в строку, карточки в 3 колонки, товар и контакты в 2 колонки, форма заявки в 2 колонки;
  - `1024px` — десктоп: преимущества в 3 колонки, боковая колонка «Камень дня», фильтры каталога сбоку и липкие.
- Отступы между секциями меняются через CSS-переменную (`--space-xl`: 40px на телефоне, 64px с 768px).
- **Навигация:** на телефоне меню-бургер. Кнопка «Меню» с `aria-expanded`, иконка превращается в крестик, меню закрывается по Esc, клику мимо и при переходе на широкий экран.
- **Hero:** на телефоне кнопка во всю ширину, ссылка под ней, заголовок 40px. С 480px всё в строку, заголовок растёт до 56 и 64px.
- **Сетки (CSS Grid):** преимущества, хиты, каталог, страница товара, контакты, форма заявки. Везде используется `minmax(0, 1fr)`, чтобы колонки могли сжиматься и не распирали страницу.
- **Flexbox:** шапка, меню, кнопки hero, действия карточки, фильтры-«таблетки», кнопки формы, подвал.
- **Карточки товара:** на телефоне горизонтальные (картинка 104px слева, текст справа), чтобы на экран помещалось больше товаров. С 480px вертикальные.
- **Каталог и фильтры:** на телефоне и планшете фильтры сверху и свёрнуты, их открывает кнопка «Показать» (`aria-expanded`). С 1024px фильтры стоят боковой колонкой и липнут при прокрутке (`position: sticky`). Варианты фильтра — крупные «таблетки» с подсветкой выбранного (`:has(:checked)`).
- **Рабочие фильтры:** категории и наличие фильтруют карточки (JS). Счётчик «Найдено камней» с `aria-live`, сообщение «ничего не нашлось», кнопка «Сбросить».
- **Таблица характеристик:** на телефоне (до 480px) каждая строка превращается в карточку «параметр сверху, значение снизу». С 480px это обычная таблица внутри `.table-wrapper` с `overflow-x: auto`: если не влезает, прокручивается только она, а не вся страница.
- **Формы:** на телефоне одна колонка, кнопки во всю ширину, главная кнопка сверху. С 768px форма заявки в две колонки (длинные поля во всю ширину). Поля высотой не меньше 44px, шрифт 16px, чтобы iPhone не увеличивал страницу при фокусе.
- **Модальное окно:** не выше экрана (`max-height: 100dvh`), длинная форма прокручивается внутри окна.
- **Нет горизонтального скролла** на всех страницах и ширинах (проверено скриптом: `scrollWidth === clientWidth`). Длинные слова в заголовках и адрес почты переносятся (`overflow-wrap`).
- Эффект наведения на карточку включается только на устройствах с мышью (`@media (hover: hover)`), на телефоне он не «залипает».

## Responsive images

- Для всех картинок действует правило `img, video { max-width: 100%; height: auto; }`.
- Каждое фото нарезано в двух размерах (320px и до 800px) и в двух форматах: **AVIF** (легче) и **WebP**.
- Карточки: `<picture>` с `<source type="image/avif">` и `<img>` с `srcset` + `sizes`. Браузер сам выбирает формат и размер под ширину экрана и плотность пикселей.
- Страница товара, арт-дирекшн через `<picture media>`: на телефоне загружается широкий кадр 4:3, с 768px — квадратный.
- У картинок заданы `width`/`height` (страница не «прыгает» при загрузке) и `loading="lazy"` для карточек.

## Доступность

- Добавлена ссылка пропуска «Перейти к основному содержимому» (skip-link). Она видна при первом нажатии Tab и переносит фокус в `<main>`.
- Видимый фокус у всех интерактивных элементов: ссылки, кнопки, поля, `summary`, фильтры, прокручиваемая таблица. Тёмная обводка 3px с контрастом больше 3:1 (раньше была светло-зелёная и почти не видна).
- Исправлен контраст:
  - оранжевый `#e0643a` больше не используется для мелкого текста (было ~2.9:1);
  - для ссылок при наведении — тёмный оранжевый `#b5441c` (4.7:1);
  - на оранжевом фоне (бейдж «Хит», кнопка при наведении, слово «ничего» в hero, номера преимуществ) текст тёмный (5.3:1);
  - активный пункт меню выделен подчёркиванием, а не цветом текста.
- На каждой странице ровно один `h1`, заголовки идут без пропуска уровней. В каталоге и заявке добавлены скрытые `h2` для секций.
- Навигация размечена через `<nav>` с `aria-label`, текущая страница — `aria-current="page"`.
- У всех полей есть `<label>`. Подсказка формата телефона связана с полем через `aria-describedby`. Ошибочные поля получают `aria-invalid="true"` (красная подсветка снимается, как только поле исправлено).
- Группы фильтров размечены `<fieldset>` + `<legend>`.
- Осмысленные `alt` (описывают, что на фото, а не повторяют название). У ссылок «Подробнее» есть скрытое уточнение, о каком товаре речь.
- Модальное окно на `<dialog>` + `showModal()`: фокус остаётся внутри, Esc закрывает, клик по фону закрывает, после закрытия фокус возвращается на кнопку «Заказать».
- Прокручиваемая таблица доступна с клавиатуры (`tabindex="0"`, `role="region"`).
- Учтена системная настройка «уменьшить движение» (`prefers-reduced-motion`).
- ARIA используется только там, где HTML не справляется сам: `aria-expanded`, `aria-controls`, `aria-live`, `aria-invalid`, `aria-describedby`.

## Самостоятельные доработки

- Мобильное меню-бургер с анимацией в крестик, закрытием по Esc и клику мимо.
- Горизонтальные карточки товара на телефоне.
- Сворачиваемые фильтры на мобильном, липкие на десктопе, рабочая фильтрация со счётчиком.
- Карточное представление таблицы характеристик на телефоне.
- AVIF + WebP, `srcset`/`sizes`, арт-дирекшн через `<picture media>`.
- Skip-link, контрастный фокус, исправленный контраст, доступное модальное окно, `prefers-reduced-motion`, `hover: hover`.
- Страница контактов с формой обратной связи.
- Публикация на GitHub Pages.
